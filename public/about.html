About This Project

📖 Overview

Task Manager is a multi-page web application developed as part of CPS 630 - Assignment 1. The application demonstrates the fundamentals of client-server architecture using Node.js and Express.js, implementing a REST API that allows users to manage a list of tasks.

Users can create, view, and delete tasks through an intuitive web interface. The application showcases proper HTTP methods (GET, POST, DELETE), status codes, and JSON data handling without requiring a database - all data is persisted in a JSON file on the server.

🛠️ Technology Stack

This project was built using the following technologies:

Node.js Express.js HTML5 CSS3 JavaScript (ES6+) REST API JSON

🔌 API Endpoints

The application exposes the following REST API endpoints:

  • GET /api/items - Retrieve all tasks
  • GET /api/items/:id - Retrieve a single task by ID
  • POST /api/items - Create a new task
  • DELETE /api/items/:id - Delete a task by ID

📄 Pages

The application consists of three main pages:

  • Home (/) - Landing page with overview and features
  • Tasks (/tasks) - Main interface for managing tasks
  • About (/about) - Project information and documentation

🚀 Future Extensions

This application was designed to be modular and extensible. Potential future improvements include:

  • Adding a database (MongoDB or MySQL) for proper data persistence
  • Implementing user authentication and authorization
  • Converting to a React-based frontend for better state management
  • Adding task editing and completion status
  • Implementing task categories and filtering
  • Adding due dates and reminder notifications
  • Creating a mobile-responsive progressive web app (PWA)
